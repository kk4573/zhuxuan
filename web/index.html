答题

自动切英文输入法

答题开始切英文、结束切回中文，免得中文输入法把字母吃掉。切换作用于整个窗口，所以你其它的 Edge 窗口也会一起变。

当天重复抑制

同一天里已经考过的词，当天再开新一轮时会少出现 —— 避免记忆还没淡就重复刷分。取值 0–5：0 不抑制，1 打对折（默认），越大抑制越强。隔天自动恢复。

释义

保留词性

一个单词常常有好几种词性（n. / v. / adj. …），这里决定答题时显示几种。

每个词性的义项

每种词性下留几条意思。第 3 种词性起会比这里少一条（最少 1 条），免得题干太长。

重新生成释义

释义是在加词那一刻算好存下来的，所以改了上面两项之后，已有的单词不会自己变 —— 点这里按新设置重跑一遍。约 0.15 秒/词，跑的时候可以正常背单词；按钮上会显示进度，中途失败了再点一次会接着跑。

DeepSeek API Key

词典查不到的词交给它生成释义。填了才启用；密钥只存本机 config.json，不会外传。
